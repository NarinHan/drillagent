# Utils Module

Utility modules for DrillAgent providing coverage analysis, logging, and helper functions.

> **Note:** LLM agent tools have been moved to `drillagent.tools`. See [../tools/](../tools/) for tool documentation.

## Modules

### llvm_cov.py

LLVM coverage instrumentation and data extraction utilities.

**Main Class: `LLVMCovUtils`**

Utility class for parsing coverage data files (profraw/profdata) generated by instrumented binaries.

**Key Features:**
- Generate coverage summary reports
- Query function coverage details (execution status, covered/uncovered lines)
- Query function region coverage
- Query line coverage (execution status, count, owning function)
- Generate HTML coverage reports
- Clear cached data to free memory (coverage data can be 50+ MB)
- Get cache information and statistics

**Usage:**
```python
from drillagent.utils import LLVMCovUtils

# Initialize with instrumented binary
cov_utils = LLVMCovUtils(
    binary_path="/path/to/instrumented/binary",
    profdata_path="/path/to/coverage.profdata"
)

# Get coverage summary
summary = cov_utils.get_coverage_summary()

# Query function coverage
func_cov = cov_utils.get_function_coverage("my_function")
print(f"Covered lines: {func_cov['covered_lines']}")
print(f"Uncovered lines: {func_cov['uncovered_lines']}")

# Clear cache to free memory
cov_utils.clear_data()
```

### logging.py

LLM interaction logging utilities for DrillAgent.

**Key Functions:**
- `init_llm_history_log(output_dir)` - Initialize/clear the LLM history log file
- `log_phase_separator(output_dir, phase_name)` - Log phase transitions
- `log_llm_interaction(...)` - Log LLM request/response interactions
- `log_tool_results(output_dir, tool_results)` - Log tool execution results
- `log_agent_loop_start(...)` - Log agent loop start with context
- `log_agent_loop_end(...)` - Log agent loop completion
- `setup_drillagent_logger(...)` - Configure Python logging for DrillAgent

All LLM interactions are logged to `llm_history.json` in JSON format for debugging and analysis.

**Usage:**
```python
from drillagent.utils.logging import init_llm_history_log, log_llm_interaction

# Initialize log file
init_llm_history_log("/path/to/output")

# Log an interaction
log_llm_interaction(
    output_dir="/path/to/output",
    phase="vuln_analysis",
    model="claude-3-5-sonnet",
    messages=[...],
    response={...}
)
```

### utils.py

General utility functions for file operations, git operations, and process management.

**File Operations:**
- `get_file_size(file_path)` - Get file size in bytes
- `is_text_file(file_path)` - Check if file is text using MIME type
- `is_binary_file(file_path)` - Check if file is binary

**Git Operations:**
- `compare_gitrepo_commit(repo_path, commit)` - Check if repo is at specified commit
- `checkout_gitrepo_commit(repo_path, commit)` - Checkout specific commit
- `clean_gitrepo(repo_path)` - Clean git repository

**Coverage/Binary Operations:**
- `check_llvmcov_binary_exists(repo_path, binary_path)` - Verify coverage binary exists
- `check_coverage_binary_exists(...)` - Check for instrumented binary
- `check_existing_coverage_instrumentation(...)` - Verify coverage instrumentation
- `locate_instrumented_binary(...)` - Find instrumented binary path
- `is_libtool_wrapper(path)` - Check if path is libtool wrapper script

**Process Management:**
- `set_memory_limit()` - Set memory limits for subprocess execution

**Usage:**
```python
from drillagent.utils.utils import is_text_file, set_memory_limit, checkout_gitrepo_commit

# Check file type
if is_text_file("src/main.c"):
    print("This is a text file")

# Checkout git commit
checkout_gitrepo_commit("/path/to/repo", "abc123def")

# Set memory limit for subprocess
import subprocess
subprocess.run(["./test"], preexec_fn=set_memory_limit)
```
